# Bundled CSL styles

These files are unmodified official Citation Style Language styles. They are
bundled so citation formatting does not fetch styles at runtime.

| file | official style ID | source |
|---|---|---|
| `apa.csl` | `http://www.zotero.org/styles/apa` | https://www.zotero.org/styles/apa |
| `nlm-citation-sequence.csl` | `http://www.zotero.org/styles/nlm-citation-sequence` | https://www.zotero.org/styles/vancouver (redirects to the official NLM citation-sequence style) |
