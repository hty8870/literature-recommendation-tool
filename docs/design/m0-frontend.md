# M0 前端说明

## 范围与视觉方向

`web/` 是本地与服务器共用的 M0 检索与候选工作台，使用原生 HTML/CSS/ES module，无第三方网页运行时依赖、外部字体或 CDN。页面只调用真实 FastAPI，不内置检索结果。本地可使用明确标识的 fixture；真实模式分别展示 Europe PMC 在线、11,002 篇多学科快照和 50 篇 aBiotech 老师样例库。候选不代表全文可引用证据。2026-11-17 本轮按用户要求扩展连续对话、全文输入及按需原文引用建议，验收以前不宣称完成；引用建议不等于自动采用、完整编号或文档导出。生产实际版本以 README 的当前发布记录为准。

界面遵循“凡有理由认为不需要的元素/信息都不引入”。组件使用大圆角，内部圆角按“外层半径－内边距”递减；支持 `corner-shape: squircle` 时启用连续曲率，其余浏览器使用大圆角回退。

## 页面与交互

- 首页只保留标题、检索模式、输入/文件入口、数据源、发送及必要的真实能力边界。模式菜单支持关键词、Abstract 和全文，具备 `aria-expanded`、Escape 关闭和焦点管理。
- 数据源来自服务端配置，默认全部选中；点击切换高光与 `aria-pressed`。前端不维护第二份库注册表。
- 关键词与 Abstract 走 `POST /api/v1/agent/runs`。自由 LangChain Agent 自主决定查询与停止，不由前端指定固定 Workflow。
- 全文模式上传实际 PDF/DOCX 并等待服务端解析/OCR，成功后发送真实 manuscript_id；同一文件选择的传输重试复用幂等键。文件 ID 不是科学评分条件。文件校验/解析失败与能力关闭时禁止检索，不伪装为 Abstract。原件不进入公共库；发送前一处披露所选模型与匿名实例隐私边界。
- 发送后桌面左侧连续对话、右侧单列排行榜；手机按需切换。综合结论只在对话出现，默认简明；结果入口绑定真实 query。整段 Query、单 Claim 回显、重复徽章、诊断面板和能力横幅不显示。
- 当前榜单内按需展开“数据源 x/n”、来源完成数进度和每库最新 Worker 卡片，不再独占第三列。来源自治路径使用真实“已发现/已提交”计数，旧逐篇路径使用“候选/已处理”；不把提交解释成核验，也不展示虚构的三步流程或“推荐 0”。失败、超时、取消不计完成；同一 attempt 的迟到状态/低计数不能覆盖新状态，新 attempt 按真实状态重新计数。Agent 最终未发起检索时隐藏来源区。
- 来源完成不等于中央排序或父 Agent 完成。标题旁根据实际榜单与运行状态有限显示“LLM 排序中”“排序未完成”“部分完成”或“Agent 处理中”，不展示推测的内部行动。结果标题与数量合并到主栏，删除独立大标题区和折叠结论分隔线；卡片共用 16px 列表间距。
- 结果按服务端身份与排名呈现。来源自治路径的真实候选卡显示 LLM 名次、共同基础分与同池名次差，以及题名、作者/年份/DOI、真实模型理由、文献类型和可展开摘要/来源；旧逐篇路径保留其独立分组，不把原始库内分拼成共同分。不重复显示 Claim，不伪装为全文证据。
- 真实候选卡保留已有题录复制；它不冒充 CSL 引文，fixture 附模拟警示。用户点击“生成引用建议”才独立请求合法原文及模型生成，按每个事实展示对应的真实片段与章节/段落，不堆放未用于句子的片段；同处显示范围限制、CSL书目和可编辑建议。XML段落ID与人类从1开始的段号只取一种，证据级别统一说明，不重复标签。无全文、撤稿或证据不足明确拒绝，不自动升级候选 citable。
- 一个 Conversation 保存多轮 AgentRun，Agent 自主决定追问是否需要新检索；每次实际工具调用仍有独立 query、Store 和 SSE。消息中的结果入口与右侧榜单指向同一真实 artifact，多榜时才显示切换，不拼接不同 query 的分数；用户查看旧 query 时不自动跳走。服务端历史可恢复，浏览器不持久化稿件正文或伪造助手上下文。
- 推荐理由仅展示服务端真实模型调用并校验通过的文本；失败显示稳定错误码，不以模板冒充。
- 结果区充分利用桌面真实可用宽度；窄屏不横向溢出。动态状态使用非打断式 aria-live，排名与状态不只依赖颜色。
- 真实候选按 `result_id` 保留卡片、摘要、来源链接和嵌套详情节点；只更新变动字段、只移动顺序确实变化的卡片。无变化刷新不增删节点，不对整行重跑淡入；更新保留焦点、文本选择与视口阅读锚点。支持 `moveBefore` 时使用原生保状态移动，其余浏览器恢复被移动节点内的焦点与选择。

## 文件职责

- `index.html`：首页、工作台、结果详情和必要确认对话框。
- `styles.css`：极简布局、圆角、焦点、窄屏和减少动效适配。
- `js/main.js`：会话、路由、复制与页面动作编排，不计算科学关系或权威分数。
- `js/home-view.js` / `search-input.js`：首页控件、模式/文件状态与请求构造。
- `js/api.js` / `sse.js`：同源 HTTP、流式读取、断线重连与水位恢复。
- `js/store.js`：单 query 的事件幂等、结果合并、Worker 单调进度与快照冻结。
- `js/agent-session.js`：同一 Conversation 的多轮 AgentRun、多个独立 query Store、消息/artifact 绑定和用户切换。
- `js/chat-model.js` / `chat-view.js`：服务端真实消息映射、稳定气泡、结果入口和条件滚底；复用 BioData 消息/帧设计，不带入其全量重绘。
- `js/conversation-storage.js`：只保存当前标签页的不透明会话 ID，正文历史从服务器恢复。
- `js/agent-run-view.js`：必要时的多查询 Pill，不展示隐藏推理。
- `js/results-view.js`：结果区协调；真实候选不显示重复 Claim 头。
- `js/candidate-card.js`：真实候选与题录复制入口。
- `js/result-card.js` / `evidence-view.js` / `detail-view.js`：fixture 推荐、证据与详情投影。
- `js/citation.js` / `clipboard.js`：已有题录的安全复制。
- `js/citation-controller.js` / `citation-view.js`：用户点击后独立请求/轮询、真实原文与限定、可编辑表述和服务端 CSL 书目分开复制，不在浏览器生成引文。
- `js/render.js` / `dom.js` / `labels.js` / `icons.js`：必要状态和 Worker、无 HTML 注入的 DOM 构建、中文标签与本地 Heroicons。

不可信标题、摘要、证据、来源名称和模型文本一律通过 `textContent` 或文本节点写入，不拼接 HTML。

## 关键不变量

- 快库结果先显示，慢库不形成首结果屏障；动态排名以服务端为准。
- 跨 Claim、跨分数尺度组不比较；候选分不是概率。
- 最终快照后冻结主列表；迟到结果单列，不改写历史快照。快照与诊断仍可通过服务端 API/MCP 获取，不要求占据主界面。
- 重连失败或序号缺口通过 GET 重建；重试不重复创建搜索。
- 初始化、模型、Worker 或请求失败显示可操作错误，不用空态或无限重试掩盖。

## 启动与验证

```bash
uv sync --frozen
uv run uvicorn citation_tool.api:create_app --factory --host 127.0.0.1 --port 8765
```

访问 `http://127.0.0.1:8765/`。`npm test` 检查前端状态、输入、复制和进度单调性；`uv run pytest` 覆盖真实 loopback API/SSE；`uv run python tools/smoke.py` 验证独立 HTTP 服务。

2026-11-15 三路版本已用真实 DeepSeek Agent 在本机完成 Europe PMC 在线、11,002 篇多学科快照和 50 篇 aBiotech 样例联合检索。DOM 与桌面截图确认 3/3 完成、每库一张卡片、同一 DOI 合并三源、真实模型理由和不可比分数 `—`；390px 首页截图确认三颗 pill 自然换行且无横向溢出。浏览器截图接口的初次 `PAGE_NOT_READY` 经重试成功，不作为通过依据；本轮未重新申请剪贴板权限，不宣称复制实测通过。旧生产发布未因本机验收自动改变。
