# 哪些论文该引，原文能支持什么？能力基准 v1

状态：**测量设计与公开题索引；未开跑**。这不是发布验收、产品需求变更、既有成绩重算或未见题已封存声明。对象是使用者最终能带走的研究成果，不是 Agent 是否按某种流程工作。适用契约见 SPEC FND-058（同池排序）与 FND-059（稿件、对话和引用建议）。

## 1. 先选值得测的东西

入选条件：错误会改变选文/写稿决策；有独立于产品的判定依据；能设计一个看似合理却应判错的近邻。核心衡量“能否完成工作”，优势是“**待验证的假设**”，基础是“错了就不能交付”。不设混合总分。

| 层 / 维度 | 怎样才算成功；主要反例 | 依据与观测量 |
|---|---|---|
| 核心 A 找对研究 | 既能凭罕见标识找准，也能在用户不用题名字眼、中文问英文文献时找到能回答问题的研究。仅关键词近似的综述不替代原始研究。 | LitSearch；新题保留词面强/弱、跨语切片。同一最终清单已知目标 Recall@5/10、首个合格位次、已审 Precision@5；检索阶段召回另报。 |
| 核心 B 选对引用角色与方向 | 明确本篇能作直接证据、反证、方法来源还是仅作背景。物种、比较对象、结局、方向、年份和研究设计须同篇成立；无显著差异不等于等效，更不等于没有测。 | Evidence Inference、SciFact、真实稿件。按对象与结果对齐的证据覆盖率、方向混淆表、明确过度推断率。 |
| 核心 C 多篇合在一起是否够用 | 用户要 A 与 B 两个独立方面，必须覆盖两方面；两个版本或同一队列两份报告未必是独立重复。有互相冲突的直接证据时须标出冲突及条件，不能投票选边。 | SYNERGY 仅用于筛选；ScholarQABench 逐题要求及双人标注的“必要证据角色集合”用于综合。前五角色覆盖、全部必要角色覆盖、有证据的冲突呈现率。 |
| 核心 D 原文与引用句 | 用户能回到正确论文、正确版本、正确段落，原文确实支持拟写句的每个实质断言。找到一段真的背景、从摘要复制同一句、或把稿件自己的结果当作外证都不够。 | QASPER、Evidence Inference、许可全文。分别报定位成功、引文逐字真实、事实–证据配对正确率、需要外证的事实覆盖率和合格引用建议交付率。 |
| 核心 E 知道何时不能引，也不滥拒 | 对硬约束不足、仅摘要可见、证据矛盾、许可不足作有边界的回答；证据齐全时不能只说“证据不足”。 | 已知有/无的成对控制 + 可审论文。分报无充分依据却断言和有充分依据却拒答两种率；开放世界的“未找到”不作绝对阴性。 |
| 优势 F 跨库身份、版本与时效 | 同篇跨库不重复；预印本与期刊版相关但证据不混抄；同名异文不误并；撤稿通知本身不是被撤稿；更正要看改了什么。 | 三来源固定回放、出版社/注册机构有日期的记录。分别报错并、漏并、版本归属错、失效研究被当正证、错误拉黑和状态未知。 |
| 优势 G 真实写稿与多轮修订 | 关键词、摘要、稿件三种入口按实际任务给同样的科学标准；用户只改一个条件，新答复改这一处、保留其他条件、旧榜单仍可复查。 | 新研究者问题；数字 PDF/扫描 PDF/DOCX 的已许可成对稿。按目标论断定位、遗漏/误判需引位置、修订满足率、保留约束率及旧结果篡改率。 |
| 基础 H 可复现、可导出、失败诚实 | 同一已存快照原样重放；新会话不必逐字一样，但不能从“反驳”漂成“支持”。多种书目格式指向同一版本；来源宕机不能说全库无结果。 | 重放/冷启动/更新库分轨；APA 7、Vancouver、BibTeX、RIS 独立字段与解析核对。完成率、记录一致性、语义翻转、失败归因与严重事件次数。 |

**不作为科学胜负项**：token、时长、工具调用次数、用了几个 Worker、是否追问、是否使用 LTR、榜单发生了多少换位、行文长度、截图好看与否。记录成本时延便于运维，不让它们冲抵错误引用。身份解析、上传解析、UI/MCP 才有的功能可做契约测试；不能因对手没有同名按钮或 SSE 接口就判它科研能力弱。现网共同基础分不是相关概率，也不是已训练上线的 LTR。

## 2. 公开锚点：每个数据集只证明它能证明的事

公开题是诊断仪，不是项目自创金标，也不是模型预训练未见题。已建索引、固定版本、题量及复建方法见 [题源清单](sources.md)；[逐题索引](public-index.jsonl) 是审计材料，不发给被测系统。

## 3. 只有这条轨道能回答“研究者用它是不是更好”

**抽样单位是独立研究需求家族，不是论文行或改写次数。** 先收自然问题，再独立检索与标注，不从已知题名反向编所有题。来源：获同意、脱敏的研究者写作/审稿需求，或独立馆员、学科研究者在未见产品表现时编写的公开可复核案例；记录两类的占比。不得取线上私稿、用户日志或把保密稿件送给外部模型。公开基准作者独立≠本产品的新留出独立。

| 主分层（一个家族只归一层，交叉标签可多选） | 先导家族 | 正式基准目标家族 | 刻意设计的最小反例 |
|---|---:|---:|---|
| 自然主题/标识与语义发现 | 8 | 56 | 稀有标识对同形异义；词面相同错对象 vs 不共用术语的直接研究 |
| 稿件中的单一引用意图与方向 | 8 | 56 | 同对象，替换结局/比较组/方法来源；研究结果不能挪到用户自己的实验上 |
| 多篇互补或冲突 | 8 | 56 | 有两篇但同一研究、不覆盖第二个必要方面；不同条件结果并不真矛盾 |
| 有证据/证据缺口、诚实边界 | 8 | 48 | 可见证据足够、仅可见摘要、补回缺失原文、资料确不足分别配对 |
| 版本、重复与时效影响选文 | 4 | 32 | 同名独立研究 vs 同一研究的多版本；公告发出前/后分别判断 |
| 正文定位、原文表述与受限材料 | 8 | 48 | 证据只在正文、脚注/表头/单位跨页；稿件里已有引文不等于外证 |
| 对话中改一个条件、保留其他条件 | 4 | 24 | “只要原始研究，先前的物种限制不变”；“解释旧榜”与“换条件重查”分别出题 |
| **合计** | **48** | **320** | 先导与正式不重合；两者目前均为设计配额，未冒充已收题。 |

覆盖设计：正式集植物/农业至少 120 家族，其他生医至少 80，跨域方法/其他学科至少 80，余 40 按招募前登记的来源补足；中文原生需求至少 96、英文原生至少 96，跨语查找至少 64（交叉标签）。输入至少 80 个关键词/短问、80 个摘要、64 个含授权附件的写作需求，其余按自然入口；不要用同一段文字机器翻译多次来凑配额。至少一半来自自然需求；报告招募渠道、领域、难度及证据可见性，不宣称代表所有研究者。近邻压力题与自然需求分报；总体仅代表预设配比。库内可达、超出现有库但公开可查、缺全文权限须在出题时分别登记，不事后排除后两者。

**小切片不是另一批独立样本。** 在上述家族内预抽 48 组正反近邻（含“可回答却被拒答”与“仅主题相关”）；24 组来源状态/顺序变化；24 份许可稿的数字 PDF、扫描版与结构化文本对照（DOCX 不要求物理页）；24 条至少两轮的修订对话；32 个家族各做 3 次全新会话，另作缓存重放。在交叉切片间重叠时只计一个主家族。正式前冻结交叉配额表、原始题序、替补顺序及附件指纹；若没有足量合格样本，报告缺口，不把重复计作补足。

**不拿产品独有的接口当优势题。** 另设计 96 对有时间戳的身份/状态材料，6 类各 16 对：同篇异标识、同名异文、预印本/期刊版、局部更正、撤稿/关切/恢复公告、状态未知或迟到。注册记录与出版社公告双向核对，找不到指定类别的双来源真例则如实留缺；其中 24 组预先选作上述端到端观察，不另加进主样本。对格式/原文另有 24 份材料：正文、表格与脚注的数字 PDF 和扫描版共享人工转录；DOCX 只核章节/段落，PDF 区分物理页与印刷页，OCR 字符误差与会改变结论的负号、单位、上下标误识分报。四种引文格式按独立样式/解析器或人工核对的参考字段判定，不以“自己渲染两次一样”当正确。权限撤销、共享源超时、断线重连等只在合法受控环境比最终可见后果；不模拟第三方入侵。这些是待取材的定向测试，不是已审金标。

**先导期怎样判断题群有无区分度**：预登记易、中、难（依据词面提示、必要证据数、近邻类型、全文才能判断与否，不看系统输赢）。逐层公开双方都对/都错/不一致的比例及区间。若一层≥90%同对或≥90%同错，只提示可能有天花板/地板；先查是否泄题、题干歧义或资料不可得，不因某侧胜负删题。易题若代表高频真实需求仍要保留；压力题若只能考榜单格式则退出科学轨但保留审计。任何重写或扩增只用于下一版、另一批家族，不倒改旧题来制造区分度。

## 4. 什么算“找到了可以用的证据”

**现实主终点：家族级「可交付」通过率**（同题两边各记 0/1）。冻结时为每家族指定一条主需求和一个交付时点；在多轮任务即预先指定的最后一轮。仅第一次分配的独立运行进入主分，翻译、扫描变体及后两次新会话只测稳健性，不挑最好也不重复加权。先由盲态标注员把需求拆成必要证据角色/命题，为每项登记一个或多个可接受的证据组合；可有“仅背景”“未指定比较组”“当前资料无法判定”等合格结论。

- 可答题：最终交付的前五个**被明确选作答案的研究**覆盖所有必要角色；每项都有身份/版本、明确的关系和与原文相符的依据，并满足用户要求的证据层级；无足以改变推荐的严重错误。只要求找方向性论文时不强求可引全文；明确要写引用句时必须给句子及合法全文定位。按用户要求少于五篇则按更小上限；金标须事先确认上限内有解。多于五篇才可能满足的系统综述只在筛选诊断轨，不混入此端点。
- 有界缺口题：在用户许可范围内没有充分支持时，明确缺的条件/来源；近邻可说明为何不足；不宣称整个学界不存在、也不拿错误版本补空。开放检索的“未见标注”不能直接定义缺口，未知由盲审或作为不确定分母处理。
- 纯解释旧榜/更换格式的任务按用户实际请求交付，不因没有新检索扣分；只测重放、导出或故障的纯工程夹具永不进入主终点。
- 推荐、作为**反证纳入**、方法、背景、仅排除、未选择等角色显式分列。论文只在“应排除”句出现不算主推；用户要找反驳文献时，明确作为反证交付的论文可以得满分。同一 Work 的重复位不补位、不增加分母中的有效结果；以后文重复改口不能抹去前一条错判。若用户看到两处互斥的实质断言，必须留下矛盾记录。
- 证据分三级，不互相代替：①身份、版次、非空逐字片段及指定坐标可回跳；②该段针对本题对象和结局；③在上下文限定下，**足以支撑/反驳这个具体表达**。整篇摘要、一个空格、装饰性引号或无关真句不能刷分。接受等价翻译/释义，但“逐字引文”必须另给原语言原句；只作书目发现时，能回查不等于 `citable`。多句共同充分时允许一组，单句缺关键条件不得满分。
- 产物对称：两边都收到同一个简短交付要求（有序选择、每条用途/必要依据、结论），均可返回文字或附件。双方都算**最终明确交付的清单/引用建议**，同样对待用户可见并被指定为交付物的附件。产品的工具轨迹、候选并集、没交付的自动建议和 Kimi 搜索笔记均不计。无清单时对两边按同一角色规则从最终正文抽取；结构解析失败可双人按原文恢复标注，不能用另一个模型替它补写。运行完成、格式有效、实际可评分、科学通过四个标志独立记录。技术故障或未交付在全分配主分母计 0；条件于有效交付的结果只作辅表。

**配套量表**（均给分子/分母，不把 N/A 当零）：

- 搜到：Recall@k=命中的已知合格独立研究数/已知合格独立研究数；nDCG@5 在有等级且判断足够的同一查询内算，直接合格=3、满足部分明确需求=2、仅作背景=1、明确错用=0，以用户意图为准。身份 unknown 不等于 0；未审时给已判比例和 Precision@5 悲观/乐观界（U 个未判产生宽度 U/5，非满列表另报填充率），不以不全 qrels 排名宣布胜负。
- 能用：把一句建议分为**可核实的原子事实**。引证正确率=充分支持的事实－来源绑定/所作绑定；完整率=有充分绑定的必要事实/应由外证支撑的必要事实。另报同篇逐字准确、错误版次、证据强度误判；“人人不说话”不会借空分母得满分。
- 会拒答：把有充分依据、受限缺口、冲突、未审四列分开。分别报 `不当断言/已确证缺口`、`不当拒答/已确证可答`；条件回答不等于拒答。另记把相反结果说成正证、只找支持证据而无视直接反证等严重项。
- 治理与稳定：同篇错拆/异篇错并各自用应并/应分对为分母，状态按 as-of 比较。重放验清单和证据指纹；全新会话报合格论文集合 Jaccard@5、必要角色保持率、方向翻转率，不以同义措辞或并列合格论文换位判错。跨时间实时库的变化须记录响应/公告时间；来源更新不是随机漂移。

## 5. 两种公平对照，加一项真正能解释重排的实验

1. **现实使用（主结论）**：当日产品（登记三来源、字段、库时间、权限与适配边界） vs 正常工具齐全的 Kimi Code。二者同实际 `OpenAI/gpt-6-luna`、同许可、同题、同附件，同家族交错顺序并在同一时间窗运行；Kimi 每家族新会话，连续对话题在该会话内按同一脚本追加。临时工作区无项目 Skill、旧答案、索引金标或评分器。保留搜索与外部工具，不要求通用 Agent 模拟产品接口。核实实际服务模型；不一致则不称同模型对比。开放世界资料的快照、访问差异和阻断单列。这回答真实使用价值，不单独归因给检索算法。
2. **同料对照（机制）**：两边可读完全相同的合法文档、元数据和全文/摘要版本；对照可用一般查找和同等文档访问，另可报告双方共用中性搜索 API 的等工具组。不给 Kimi 产品评分，亦不给产品目标题录。跨域库尚未适配时仅能报告适配缺口，不能让一边查不到库再比较。与产品比较只看同型最终交付，另与 BM25、向量单路、RRF 对照候选召回；若未来有 LTR，只用异家族训练/验证，独立评测数据不能训练。预建索引等投入及双方资源分别登记，不限制有效补查次数。
3. **同一候选池的配对消融（产品内诊断）**：固定一个需求、候选 ID/版本/证据与窗口，保存共同基础榜和**同一次**盲排；再比较此次盲排与揭分复核。按盲态专家的 graded nDCG@5、必要角色覆盖及严重误升/误降判变化，报“改好/改坏/没变”，并单列盲排失败、复核失败回退、无需揭分。只在池和盲排输出完全相同时归因给第二步；位置交换本身不是增益。逐阶段拆为“源召回→源提交→去重池→基础榜→盲排→复核→父 Agent 最终交付”，记录每步丢失的合格研究/角色；不把这当 Agent 行为约束。

## 6. 独立标注、样本有效性与如何宣布胜负

**金标先于输出成立。** 题目编写者不调产品；至少两位独立标注者（该题学科研究者 + 受训证据审查者）各自判角色/方向/出处，分歧交第三人，保留原判与理由。先导 48 个全双标，公布分类原始一致率、关键标签 Cohen κ、类别基率及分歧类型；主标签目标 κ≥0.70，低流行率时同时看分项混淆。达不到或出现系统性歧义，修规则、换新先导并重新冻结，不硬判。正式集双标所有主端点和严重错误。模型可定位候选，不能独立给自己出题、仲裁或认证语义真值。

**参考集不可能穷尽**：预先用独立馆员检索/综述、可审近邻建立首版；正式输出锁定后，对两边前十、独立检索基线及预选未入池随机尾部去重、随机化匿名，逐条判新增记录。向评审隐藏系统、排名、基础分、LLM 理由出处及哪方提出替代项；需要评完整答复时再看按原顺序的匿名答复。新增有效证据按同一标准对双方生效；保存金标增补有效期、版本与理由，不改首版、不据此重跑系统。未授权或仍无法裁决的留 `unknown`，给双方最不利/最有利界；主结论若随判法反转则结论不确定。

**隔离与盲态冻结**：按中心论断/研究、试验注册/队列、预印本-期刊链、纠撤通知、引用源稿、翻译/多轮/格式变体的连通家族分组。主题标签相同不是自动同家族。与老师样例、旧 Astra/SciFact、公开题、开发日志、LTR 训练/调参记录跨来源查重（稳定 ID、题名近重复、人工主题核验）；共用无关背景文不串成巨簇。留出只由独立保管者持有，双方只获 `public_request` 和许可材料。预先签名/哈希需求、题序、证据许可与时间、评分手册、产品/基线版本；评测后调参则本批降为开发，另换独立确认批。公开题自动检出榜单/答案页记泄漏，不能声称模型没见过。

**样本量与结论**：先导 48 家族用于检查可判性、类别难度及匿名汇总的两边分歧；不是证明优效。正式主比较是一项预设的配对二元端点，最低实用差暂定 10 个百分点。规划例：若有 40% 的家族两边一过一不过，想在真差 0.10 时以约 80% 把正差与 0 区分，双侧 5% 的近似量级 `ceil((1.96+0.84)^2 × 0.40 / 0.10²)=314` 个独立家族，取 320。若分歧率为 0.50，约需 392 个，向上取整到 400；若聚类或分层方差更高则扩招或标“未达精度”。这些是假设，不是实测功效；不是“有 80% 概率证明差值超过 10 点”。锁定正式题前只用独立先导的盲态分歧率定最终 N 并按原配额比例取整，禁止看胜负边跑边补。

公布双方绝对通过率、配对百分点差、各家族胜/平/负及按主分层、家族重采样的 95% 区间（10,000 次，固定种子 `20261119`），同时报配对不一致格与 McNemar 精确检验作敏感性分析。一个主终点；其余切片描述性，不从几十格挑唯一显著项。只有现实轨点差≥10 个百分点、区间下限>0、且预设严重错误护栏通过，才称为“在该人群和配比上观察到实用优势”；若下限也>10 点才称“优势至少 10 点”。严重错误以家族为单位：虚构/错绑原文、不标明地把已撤稿文献作有效正证、把直接反证说成支持，任一即为一次；产品相对对照的严重错误率差，单侧 95% 配对上界须 ≤+3 个百分点（用配对二项风险差的 score 区间；零事件不使用退化的零宽 bootstrap，样本不足即不确定）。绝对次数分类型披露；工程红线如泄露授权外材料独立阻断上线判断，不能用科学优势抵消。只赢同池消融或某一领域就只声明那一项；负结果、无差异和证据不足都是有效结论。
