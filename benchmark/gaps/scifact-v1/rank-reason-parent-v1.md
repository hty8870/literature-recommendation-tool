# SciFact：主 Agent 的榜单生成理由披露对照

## 假设与单变量

完整同期 28 题的默认产品召回 @10 为 95.0%，正确方向且引文逐字为 78.3%；普通 Kimi 为 96.3% 和 81.7%。`sf-1029` 与 `sf-528` 的四个独有差异目标均已送达标注原句，默认产品在终稿给 `INSUFFICIENT`。原有排序理由同报测量或范围限制，但方向与正式引用资格是不同问题；上游生成理由可能成为主模型的判断锚点。这是可证伪假设，不把合理的科学保守判成模型错误。

两臂同一产品实现、父提示、Luna Responses 默认推理档、5,183 篇题录摘要、真 E5/RRF、榜单与排名理由生成、引用资格和终稿守门。只切换现有 `CITATION_AGENT_PARENT_HIDE_RANK_RATIONALE`：变体只从父 Agent 实际收到的候选回执去掉生成理由的 `reason.text`，保留原文、书目、状态、排序、资格字段，网页/保存榜单不变。资料空间与上下文实验均关闭。主 Agent 自主用工具，不新增固定步骤或反思轮。
