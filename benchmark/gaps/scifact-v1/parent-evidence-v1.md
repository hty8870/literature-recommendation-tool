# SciFact：论文家族隔离与父 Agent 证据交付验证

本协议是新诊断，不改旧 28 题分数、数据或协议。只回答：在相同候选证据下，能否减少把“没有全文引用资格”错读为“摘要没有方向证据”；若通过，再检查真实自由 Agent 的端到端后果。训练集用于提示与接口开发，**不微调 Luna、不训练 LTR**。

## 划分与权限

- 仅用已固定归档的原始 `claims_dev`（300）及 `claims_train`（809）这两组有标注数据。上游 `claims_test` 无标注，不使用。池底仍是原 5,183 篇摘要，所有组有相同检索库；隔离的是问题－论文家族与标注用途，不是把测试所需论文移出库。
- 共享原论文 ID（`cited_doc_ids` **或**正式证据 ID）、同规范化标题（≥4 词）或同规范化摘要（≥20 词）、同规范化论断或词二元组 Jaccard≥0.8（至少 5 个二元组）的论断取连通分量。标题同名可能被保守地分在一起；不能保证识别数据库未提供的同试验异文，也不保证大模型预训练未见。
- 原始开发集曾跑过全量检索，连同所有相连项只进训练。其余家族按多文献、支持、反驳、证据缺口优先分层，层内固定哈希顺序。去除历史相连家族后只有 15 个独立多文献家族，预分 4 组验证、8 组测试、其余训练；其他层每 20 组中 3 组归验证、5 组归测试、其余归训练。仅用 ID 和官方标签定样本，**不以系统得分或检索是否命中替换样本**。训练重放取历史已测题 12 个家族；验证重放 16、测试重放 28，另预留 8 个不相交测试家族做产品端到端。允许选样前因配额不可行而调整一次协议，第一次模型调用后不可调。
- 仅在当期发送原题、相同的公开题录摘要和必要运行上下文。题目标注及其辅助索引只在评分端；本文、家族、分组理由不进入请求。完整划分在 `data/runtime/benchmark/gaps/scifact-v1/parent-evidence-v1/splits.json`；它没有问题、答案或目标论文列表。冻结分组指纹、归档和评分实现；已看测试结果后做的新改动必须用新家族验证。

## 配对对照

- `legacy`：既有父工具回执语义。`separate`：仅省略 `abstract_metadata_only` 候选未判定的 `relationship=insufficient` 占位，保留资格拒绝理由。`scoped`：再解释完整命题与子命题、对照组与组内改善的差别；仍要求结论只及原文。三者不改变论文、摘要、排名、资格、公开 API 或检索步骤。
- **固定池诊断**：用当前 BM25+E5/RRF 对每条原始论断构造一次实际候选列表，保留原身份、原始摘要和查找顺序；不使用金标补候选，不伪造重排、理由、全文或证据。这是单次同池综合诊断，不是自由检索。相同题面、内容、顺序、产品基础 Skill、实际 API 模型及配置；唯一差异是上述回执语义。对同题交错调用，各请求无共享对话。API 请求 `store=false`；实际响应须验证 `gpt-6-luna`。运行失败计入；不作多次采优。
- **全产品**：如重放测试达到门槛，在独立的 8 个家族用生产父 Agent、真实来源召回、重排和最终证据守门对照。两臂查询/池允许因决策而不同，不把 E2E 差值归因于单次模型合成。排查性能不要求改 LTR、强制步骤或限有效补查次数；不对比 Kimi 或宣称优势。

## 计分与决策（先于输出）

- 主指标为等家族权重的正确方向且逐字证据覆盖（先按题均分），只给非重复、非过短（≥4 词）且**确实提供或已经召回到父 Agent**的原文积分。另算同时覆盖任一完整官方原句组、最终 Recall@10、配对胜／平／负及描述性家族 bootstrap 95% 区间。片段精确不等于语义充分，完整官方原句不是唯一写法。不可用、格式失败、池未命中计作零覆盖，不因素材不足而事后排除。
- 护栏：完成率、格式有效数、Recall@10 与完整原句组覆盖不降低；明确反判（`SUPPORT` ↔ `CONTRADICT`）、未见/伪造 ID、非逐字/过短引文、重复 ID 不增加。`INSUFFICIENT` 和明确反判分开。无金标题的方向断言单列，既不计正确，也不自动罚错；若增加则在通过护栏前需要独立原文复核，未复核不能通过。对领域语义或复合论断的争议不改金标，另注边界。
- 两个变体均在训练和验证以相同安排实跑。入围需在验证主指标至少 +5 个百分点且通过护栏；多者选主指标增益较大者，同分选 `separate`。只有选定变体对比基线才解锁测试；不能看完测试改选另一个。保持训练与验证结果，允许无变体入围。
- 测试主指标至少 +5 个百分点、至少 3 个胜家族、护栏同时通过，才开端到端保真验证。端到端至少不退化且护栏通过才可考虑开启产品默认。测试切片、描述区间和不完备金标不够证明真实科研普遍优势；不发布、不修改服务器。
