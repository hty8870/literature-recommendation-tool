# SciFact：用 DSH 替换主 Agent 循环的同工具试验

目的：已完成 28 题时期对照；原文送达后的终稿判断是主要已见差异。隐藏生成理由的数值增益在重复运行未达门槛，停在开发。检查是否由主循环/上下文呈现带来可用增益，而非先更换模型、检索器、排序手段或扩大资料权限。

## 接入门槛（不作质量评分）

- 只用本机已安装、版本核实为 `0.1.0-rc.6` 的 DSH 核心循环。开发脚本不加载其通用工具、用户配置或持久历史；工具和提示只来自当前显式会话。Shell、宿主文件、出网检索和跨会话访问均不装载；这不是操作系统沙箱。离线工具探针不能替代实际 Luna。
- 真实预检使用服务端生成的公开随机字串，从指定只读工具取回再逐字返回。核实至少一次工具回执进入真实后续模型请求、终稿、实际模型及 provider `store=false`。凭据只由现有 Python 网关在内存使用，子进程、临时工作区和产物不接触 provider 密钥。不得修改 Kimi/DSH 全局配置或生产。

## 同工具开发配对

- 仅在预检通过后，冻结 `sf-1029`、`sf-528`、`sf-873`、`sf-1187`、`sf-1137`、`sf-437`。六题均为已见开发诊断，原始官方数据不改；Gold 不发送。新开独立运行和数据库，以同版产品默认父 Agent（不隐藏生成理由，不开资料空间）和试验 DSH 各执行一轮。原 28 题 Kimi 记录只作背景，不把普通 Kimi 的工具或跨库能力算入同工具成绩。
- 仅替换父级循环。原始系统提示、父工具定义、权限、输出协议、真 E5 及候选/排序/理由、终稿守门同源。模型继续官方 `gpt-6-luna` Responses 默认推理档；字段及上下文变换要可核验，调度与消息格式不可避免的不同要记录，不冒充逐字等同。如果传输路径也显著改变，结果只适用于这套替换组合。整个老产品路径始终可用，不加固定检索或反思。
- 沿用原冻结评分，按终稿分报方向＋逐字、召回、完整证据组、错误方向、未知标识与技术失败。额外检查新增未标注方向断言，不把摘要候选升级为全文引用。六题筛选要求主分至少 +5 个百分点、至少两独立家族获益且有效完成、Recall@10、完整句组不退化，反向错误/非逐字/虚构标识不增加；新增方向须原文复核。通过也只是决定是否继续独立验证，不上线或开默认。环境、可见工具或有效调用未证实时，不用模拟成绩替代。
