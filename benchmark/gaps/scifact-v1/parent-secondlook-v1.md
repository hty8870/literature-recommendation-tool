# 父 Agent 的独立证据复看：训练筛选

这是开发数据上的工作流机制筛选，不是新的产品工作流。使用 [证据方向对照](parent-decision-v1.md) 已封存的 12 个训练题、旧提示真实终稿和完全相同的候选池。未通过筛选，不打开任何新验证或测试；即使通过也不能未经真实端到端证据就增加必经步骤。可用的候选产品形式是由 Agent 自主选择的只读证据复看工具。

1. 只对基线没有列出、或明确标为 `INSUFFICIENT` 的池内论文做一次独立复看。保留原题和真实同篇题名、摘要，不给已有方向标签、推理、库分、榜单名次、金标或前一次对话。只接受发现直接相关观察且能给出同篇连续逐字片段的支持/反驳，不强求作答。新生成判断仅在 `json_object` 的真实最终块、本次提供的候选身份、唯一性和逐字依据均通过后使用。
2. 基线已肯定的方向原样保留；复看可替换同一论文的证据不足条目，或将新找到的条目按复看模型的顺序附在尚未占用的名额中。不删基线条目腾位置，不改其结论。正式引文资格不变。原答复或复看失败有单独状态；不重试挑优，不把失败的第二次请求当作成功。
3. 正式质量仍按原计分、同一 10 篇输出上限。达到 **+5 个百分点且所有既定护栏通过**才值得在此前未做此对照的验证家族确认。无金标新增断言不能自动算错，也不能在未独立原文复核的情况下放行。报告同池训练增益、附加调用、失败、无标注新增断言，并明确这是带可选复看的固定证据实验，不是产品答复或科学真值。
