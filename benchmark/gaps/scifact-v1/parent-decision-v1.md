# 证据方向与证明强度：父 Agent 配对验证

先核实 Responses 交付边界。`luna-output-phase-probe-20261119` 仅用旧训练题，记录了实际 API 的 `commentary` / `final_answer`，无原始思考或凭据；发包仅核实 `json_object` 生效，不把 `json_schema` 的一次有效答复说成已使用严格 schema。新两臂同用 `json_object`，只读最终消息；无阶段的提供方仍可使用原文本，明确进度不计作终稿，截断不算成功。另记录旧拼接器是否能解析作诊断，不用推测前言、尾部截取或自动补 JSON。历史实验不重算或覆盖。

- 冻结原分组、5,183 篇摘要与生产混合检索。训练先用原 12 家族；新验证仅取原 16 家族之外的验证家族，按固定哈希依次选 6 `contradict`、6 `support`、4 `evidence_gap`；优先保留较稀少的反驳家族。验证组中全部多论文家族已用于旧实验，所以新确认不测未见多论文题，不能声称该层已验证。只按分层、ID 和家族选，不看模型输出或命中。留出原 28 家族及独立的 8 个端到端家族不动。
- 两臂候选、顺序、文本、父模型推理档（API 默认）与题面完全相同。`legacy` 使用现有提示；`rubric` 只增加一段通用证据判断说明，区分原文在实际范围内支持的方向、是否完整支持论断、外推及因果。原证据回执和资格字段不变，无额外模型步骤，不引入案例定向示例。先跑训练，不根据训练分数调题；另跑验证。新固定池不仿造模型重排理由。实际响应模型必须为 `gpt-6-luna`，`store=false`；交错顺序、每次单个在途回放请求、同题无共享对话。
- 继承 `parent-evidence-v1` 的证据、Recall@10、格式/完成、反判、原句组和来源护栏。验证 +5 个百分点且护栏不退化才开 28 家族留出；留出同门槛且至少 3 胜家族才开真实端到端。主指标是方向匹配加逐字引文，不等于语义充分；增加无标注的方向断言仍需独立复核，而不自动判错。没有验证就不默认启用。端到端继续使用自由父 Agent 的正常工具协议与证据守门。
